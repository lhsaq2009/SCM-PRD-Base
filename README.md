# 功能

* 一个提供 UUID、ULID 和时间戳 ID 生成的 PHP 公共工具库

# 安装

```shell
php composer.phar require sccp/common-utils
php composer.phar remove yiisoft/yii2
php composer.phar update 

# 只更新 sccp/base 以及依赖项 
php composer.phar update sccp/base --with-all-dependencies
```
